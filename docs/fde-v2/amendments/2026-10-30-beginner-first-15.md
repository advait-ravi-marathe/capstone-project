# Beginner-first active instructions for Days 1–15

This versioned amendment changes the active teaching instructions on Days 1–15. It does not rewrite accepted source contracts, historical schedule receipts, or learner evidence, and it does not mark any work complete. The canonical per-day map is [`2026-10-30-beginner-first-15.json`](2026-10-30-beginner-first-15.json).

## The route

For each of the first 15 days, the budget is **60 minutes of DSA in the separate repository + 30 minutes of AWS learning + 90 minutes of guided AI/Python learning = 180 minutes**. The AWS block is active study, not a role-gap review. If DSA takes longer, reduce the AI block and carry work forward.

Each AI block has a pinpointed reading, a worked example, one small learner-owned function and a targeted check. The assistant supplies the application, fixtures, test runner and data-store setup. The learner does not build the UI, API or whole application. Days 1–11 and 13–15 use a separate beginner exercise module so the supplied demo remains runnable while TODOs are unfinished. Day 12 practices the existing CoverStory record-validation seam. Days 14–15 connect the beginner search functions into source display and a complete local keyword-search response.

Python documentation is the default learning resource. Optional Udemy lessons are identified by exact title and duration in the JSON map; the catalog is a candidate resource with access unverified. Skip a lesson if it is not already available. There is no purchase or enrollment requirement.

## Hand-off to Day 16

Days 14–15 now continue the same beginner keyword-search exercise: format source labels/no-match output, then compose a new query over the supplied ten-record corpus. They do not take over the historical U011 time allocation or implement database ingestion.

None of the beginner-first Days 1–15 satisfy U011, embeddings, RAG, or Day 16 prerequisites. Completing this first-15 learning sequence and becoming eligible to start Day 16 are separate statuses. The historical Day 16 page is not ready as the next lesson until the original prerequisites are taught and accepted; see the [prerequisite handoff](day16-prerequisite-handoff.md). The accepted U011 contract remains unchanged.
