# Conditional M3.3–M4.2 build guide

**Status: proposed conditional study/build detail, not activated days or learner completion.** The accepted outcome contracts are unchanged. These lessons preserve existing daily minutes, use synthetic/local fixtures, and do not contact users, provision AWS, call a model, or grant external-write authority. The learner files contain intentional TODOs; reference code is selected only by explicit test configuration.

## Shared budget and evidence rules

Every actual day remains DSA 60 + role/AWS bank 30 + AI 90 = 180 minutes. A 75/90-minute DSA session reduces AI to 75/60 minutes and carries the same ordered work forward. Visibility is 30 minutes every seventh actual day inside the 90-minute AI allocation. The schedule JSONs count it once. Buffers are reserved for repair/retest; the remaining AI minutes are explicitly unallocated. No task can be squeezed into extra hours.

For each 150-minute stage, use 30 minutes targeted study, 20 worked example, 80 learner implementation/testing, and 20 evidence/error log. For 90 minutes, use 20+10+50+10; for 60, use 10+10+30+10. Incomplete work carries; it does not become complete because a day elapsed. Evidence labels are `PASS` for only the tested layer, `FAIL`, `BLOCKED`, `INVALID`, or `NOT_RUN`. Reference tests and test fixtures do not establish learner capability, user feedback, customer impact, production reliability, model quality, or a cloud deployment.

The suggested initial criterion is at least 10 of 12 held-out task outcomes correct, **zero** deterministic authorization violations, and complete denial/recovery evidence. It is a proposed small exercise threshold, not a general performance claim. The split receipt binds each case ID to its root group and development/held-out partition; the release gate recomputes its digest and checks group disjointness and held-out membership. A frozen report with fixtures remains `BLOCKED` for actual planning-model and human-denial evidence. Unknown or uncertain side effects require reconciliation; “at most one observed effect per exact approval” does not mean exactly-once delivery or guaranteed completion.
