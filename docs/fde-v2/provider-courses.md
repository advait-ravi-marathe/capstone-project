# Official provider courses as reading substitutions

This is a small overlay on the existing recommended 382-day route. It does not add sessions or alter the daily allocation: **60 minutes DSA + 30 minutes interview/AWS + 90 minutes AI**. The OpenAI Academy course time below replaces only overlapping AI concept-reading time in the named existing sessions. Keep each session's worked example, learner task, evidence log, and required implementation documentation. If a course takes longer than its estimate, stop at the allocated time and continue the existing offline exercise; do not borrow from another block or claim course completion.

The route still begins with the existing 270-day AI/FDE core and 112-day production-ML extension. This is our custom learning route, not an official OpenAI roadmap. OpenAI Academy courses support selected concepts; they do not cover all classical ML, statistics, PyTorch training, evaluation, or production-ML practice in this route. The linked primary technical documentation and hands-on learner tasks remain necessary. Course study is not a prerequisite substitute, practical-capability pass, or evidence of learner completion. Follow the stated milestone prerequisites before using a course slot.

### Reading precedence and course resumption

The **M2.1 Days 43–48 course chunks are deferred by default**. Those sessions already require group-split design, annotation/source-span and provenance work, SQLite transaction concepts, and Qdrant point-ID/upload/idempotence/delete/filter concepts. OpenAI Academy's general RAG material does not replace the [GroupShuffleSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupShuffleSplit.html), [SQLite transaction](https://www.sqlite.org/lang_transaction.html), and [Qdrant points](https://qdrant.tech/documentation/manage-data/points/) readings. The lesson/task and its required reference come first. Use a course chunk only if that required work is complete within the existing AI block and the chunk fits without displacing anything else; no spare minutes are assumed.

If a chunk does not fit, pause at that exact course section, record `in_progress` and the next section, and resume only in a later already-scheduled compatible course-replacement or genuine repair slot. No such later slot is guaranteed. If none is available, leave the course incomplete and badge unverified; do not add time, skip ahead, or borrow from another block. When DSA runs 75 or 90 minutes, AI falls to 75 or 60 minutes; optional course time is skipped first and the course can resume later only if a compatible slot exists.

The five catalog-listed course estimates total **340 minutes**. The map adds a planning allowance of **20 minutes per assessment**, for **440 minutes maximum**. Of that, 320 minutes are mapped into later milestone reading slots; the 120 M2.1 minutes remain conditional and deferred by default as described above. The assessment allowance is our estimate, not an OpenAI-published duration. If an assessment exceeds that allowance, carry it into a later already-scheduled course-replacement slot or a genuine repair slot only if that does not displace learner implementation, evidence, DSA, or interview/AWS work. Otherwise defer the course and leave its badge unverified; do not add time or drop an assigned task.

OpenAI says course badges require course completion and an assessment score of at least 80%. A certificate for the five-course API learning path requires all five courses and assessments; this map includes all five courses but does **not** claim its certificate or completion. OpenAI says Academy badges and course-completion certificates are **not professional certifications**. See [OpenAI Academy access and credentials](https://help.openai.com/en/articles/20001270-openai-academy-courses).

## Status and evidence

The starting status in [`provider-courses.json`](provider-courses.json) is `not_started` for every course and `not_verified` for every badge. Keep course completion and badge verification separate:

- `not_started`: no course completion evidence recorded;
- `in_progress`: a course has been started but is paused; `resume_section` records the next unfinished section;
- `completed`: the learner has completion evidence, but no badge has been checked;
- `badge_verified`: the actual platform badge and its requirements have been checked and recorded.

Do not infer progress from scheduled days or assistant-authored mappings. Do not mark a course or badge complete without actual learner evidence. These course states never change the separate practical milestone gates. No existing task or required technical reference is deleted; only the named overlapping concept-study minutes are replaced. The original reference links stay in their milestone guides. If a reference is needed to complete the task, consult it during the preserved task work; if time does not permit that, defer the optional course rather than skipping the reference or task.

AWS SAA remains the selected AWS exam under its existing readiness and separate authorization gates. OpenAI's formal Certified app access is currently described as invite-only for Enterprise/Edu workspaces; access is unverified. No such access or credential is promised here. There is no course enrollment, API-key setup, provider call, paid lab, or exam purchase in this amendment. The OpenAI Academy help page says its courses are free and globally available to people with a ChatGPT account; this document does not enroll the learner or change account settings. The 382-day curriculum remains our custom roadmap using selected official OpenAI course material and AWS cloud study, not an official OpenAI curriculum. The remaining statistical and ML training work is hands-on practice with its primary references, not claimed Academy course content.
