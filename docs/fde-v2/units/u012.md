# AIFDE-V2-U012: Chunking with source provenance

**Learner status: Not started.** This is a dependency unit, not a calendar day. Scheduled segments: Day 16: primary 90 min, Day 17: support 30 min.

## Prerequisites

U011; use a versioned document body.

## Learn

A chunk is a bounded substring plus source identity, version, and half-open character offsets `[start_char,end_char)`. Offsets refer to Python Unicode code points in the exact stored text. Overlap can reduce boundary loss but duplicates tokens and storage. Character windows are not token windows; no chunk size is universally best.

Reference: [Qdrant points](https://qdrant.tech/documentation/manage-data/points/) (payloads); the source-offset contract is local and defined here.

## Learner-owned task

Implement deterministic `chunk_document`: bounded maximum character span, configured overlap, stable ordinal IDs, nonempty trimmed text, exact source offsets.

**Learner seam:** `learner.chunk_document(document, max_chars=720, overlap=80)`

## Acceptance

Each emitted text equals the source substring at its recorded offsets after only documented edge trimming; IDs identify document/version/ordinal. Maximum span holds; adjacent chunks overlap without gaps in source coverage. Reject empty text, invalid sizes/overlap and malformed documents. Include a short, empty and multi-window test.

**Command:** `python3 -m unittest ai.fde_v2.learner_acceptance.test_continuation_units.ContinuationAcceptance.test_u012_chunk_provenance`
