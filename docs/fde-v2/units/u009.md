# AIFDE-V2-U009: Thin React workflow

**Learner status: Not started.** This dependency unit can span multiple actual study days.

## Prerequisites

- AIFDE-V2-U008

## Primary task

Use existing React/TypeScript skills to build a minimal question/answer screen with loading, empty, cancel/error and result states; avoid visual-polish work unrelated to the workflow.

## Outputs

- CoverStory UI
- frontend state tests
- local screenshot

## Acceptance

- The UI calls the real backend and shows a real generated answer.
- A failed/canceled request cannot leave the UI falsely showing success.
- Explain the frontend/backend contract and one accessible error-state choice.

## Time budget

Primary: 90 minutes; support/buffer: 30 minutes.

### Acceptance selector

```sh
npm --prefix frontend run test:fde-v2
```

These UI tests use deterministic HTTP responses to verify loading, error and result behavior. They do not establish real inference or learner completion.

Assistant scaffolding, deterministic test witnesses, generated artifacts and elapsed dates do not count as learner completion.
