## Acceptance

- A real HTTP request returns actual model output.
- The default `/generate` route invokes the learner implementation; it does not silently substitute the instructor reference.
- The supplied service loads the model once and rejects an overlapping generation request with HTTP429; this is a bounded local policy, not a throughput benchmark.
- Invalid input, timeout and unavailable provider paths are tested.
- Separate deterministic mocked unit tests from the real-model integration receipt.
