## Prerequisites

## Learn

Separate development examples used to choose retrieval settings from held-out examples used once for a final check. Keep answerable, unanswerable and adversarial/instruction-conflict cases distinct. This small synthetic fixture has 30 cases and is a teaching instrument, not an unbiased or independently authored benchmark.

Reference: [Scikit-learn: Data leakage](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage) explains keeping evaluation data separate; this fixture contract defines the case counts.

## Learner-owned task

**Learner seam:** `Fixture/label review, not a learner Python function.`

## Acceptance

Held-out cases are never fed to tuning commands. A second reviewer is preferred but must not be claimed unless one reviewed the labels.
