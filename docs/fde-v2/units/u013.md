## Learn

An embedding maps text to a numeric vector. Cosine similarity compares direction and is commonly used for semantic similarity; dot product also depends on vector magnitude. Dimensions and normalization are model/config properties, not guesses. Use tiny hand-computed vectors for arithmetic only; they are not embedding evidence.

Reference: [Sentence Transformers: Computing Embeddings](https://sbert.net/examples/sentence_transformer/applications/computing-embeddings/README.html) and [Semantic Textual Similarity](https://sbert.net/docs/sentence_transformer/usage/semantic_textual_similarity.html). The loader uses local files only and disables remote code.
