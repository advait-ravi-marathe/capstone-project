# AIFDE-V2-U017: Retrieval comparison and inspection

**Learner status: Not started.** This is a dependency unit, not a calendar day. Scheduled segments: Day 22: primary 30 min, Day 23: primary 60 min, Day 23: support 30 min.

## Prerequisites

U014–U016; real embeddings required for a semantic comparison claim.

## Learn

Compare retrieval methods over the same questions, source mapping, k and denominator. Recall@k measures whether any known relevant source appears in the first k; reciprocal rank uses the first relevant source. Inspect misses. BM25 scores and cosine similarities use different scales and must not be directly interpreted as comparable confidence.

Reference: [Sentence Transformers: Semantic Textual Similarity](https://sbert.net/docs/sentence_transformer/usage/semantic_textual_similarity.html); [Qdrant Search](https://qdrant.tech/documentation/search/).

## Learner-owned task
