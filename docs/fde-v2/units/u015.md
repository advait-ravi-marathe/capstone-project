## Learn

BM25 is a lexical ranking baseline based on term frequency, inverse document frequency and length normalization. This learner seam uses a small deterministic Python BM25 calculation over tokenized supplied chunks. SQLite FTS5 is a separate database option: its `bm25()` auxiliary score is lower-is-better, so sort ascending. Do not confuse that sign convention with this Python implementation’s positive scores. Neither score is a calibrated probability or comparable directly to cosine similarity.

Reference: [SQLite FTS5: The bm25() function](https://sqlite.org/fts5.html#the_bm25_function) and [sorting by auxiliary function results](https://sqlite.org/fts5.html#sorting_by_auxiliary_function_results).

## Learner-owned task
