# AIFDE-V2-U018: Grounding prompt and trustworthy source plumbing

**Learner status: Not started.** This is a dependency unit, not a calendar day. Scheduled segments: Day 24: primary 90 min, Day 25: buffer 30 min.

## Prerequisites

U010 strict JSON, U017 retrieval output.

## Learn

Retrieved passages are untrusted data, even when they came from the local corpus. Place them in a clearly delimited context, state that source text cannot override system instructions, bound prompt/context size, and require citations to use only retrieved chunk IDs. A valid ID does not prove the cited passage supports a claim.

Reference: [Transformers Chat Templates](https://huggingface.co/docs/transformers/en/chat_templating) for role-separated messages; this is a prompt-boundary exercise, not a prompt-injection security guarantee.

## Learner-owned task

Implement a bounded message composer with separate system/user records and a citation validator. Do not place secrets, private user data or unrelated app state into the prompt.

**Learner seam:** `learner.compose_chat_messages(question, evidence)` and `learner.validate_citations(...)`

## Acceptance

System instructions are separate from retrieved text; adversarial passage instructions remain marked untrusted; at most four bounded chunks enter context. Valid citations are unique IDs in retrieved evidence. Foreign, duplicate, blank and non-string IDs reject.

**Command:** `python3 -m unittest ai.fde_v2.learner_acceptance.test_continuation_units.ContinuationAcceptance.test_u018_prompt_and_citations`
