## Prerequisites and source

Prerequisites: U018 safe prompt boundary, U020 explicit abstention, and U022 input/data boundaries. Read OWASP GenAI Security Project [LLM01:2025 Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/). Prompt instructions are not enforced permissions; this supplied local app has no tools or external-action capability.

## Day30 authoring slice

Create `artifacts/u023-day30/adversarial-dev.jsonl` with exactly one small synthetic case for each scenario: `indirect_instruction`, `misleading_evidence`, and `access_boundary`. Each record must have a unique bounded `case_id`, scenario, clearly synthetic `document_text`, explicit expected deterministic boundaries (`tool_permission`, `filesystem_permission`, `external_action_permission` all false), and `observation_status: "not_run_day30_scope"`.

Use [`U023 Day30 boundary notes`](../templates/u023-day30-boundary-notes.md) to record what the supplied app can enforce and one limitation. Do not put real secrets or private data in a canary. Do not claim any model behavior was tested.

Run the structural checker after authoring the JSONL:

```sh
python3 scripts/fde_v2_check_adversarial_fixtures.py artifacts/u023-day30/adversarial-dev.jsonl
```

Its output reports only fixture shape and explicitly keeps `model_behavior=not_run_day30_scope` and `u023_complete=false`. Instructor tests use an independent known-good fixture set and malformed mutants. A checker pass is not proof of model resistance.

## Later U023 scope
