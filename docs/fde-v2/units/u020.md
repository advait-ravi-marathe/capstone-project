## Learn

A retrieval score threshold is an explicit heuristic, not truth or calibrated model confidence. Empty or weak evidence should lead to a clear uncertainty/clarification result. Separate retrieval failure from a generated answer unsupported by evidence.

Reference: [Sentence Transformers: Similarity Calculation](https://sbert.net/docs/sentence_transformer/usage/semantic_textual_similarity.html#similarity-calculation).

## Learner-owned task

Implement `should_abstain` on development unanswerable cases. Document the chosen cosine-score threshold and inspect at least one false positive/false negative. Do not use held-out cases for threshold selection.

**Learner seam:** `learner.should_abstain(retrieved, minimum_score)`

## Acceptance

Empty retrieval abstains; scores below threshold abstain; the exact boundary follows the documented inclusive/exclusive rule; invalid threshold and non-finite score reject. Actual answer-quality evaluation remains a manual review of generated claims against evidence, not a score alone.

**Command:** `python3 -m unittest ai.fde_v2.learner_acceptance.test_continuation_units.ContinuationAcceptance.test_u020_abstention_boundaries`
