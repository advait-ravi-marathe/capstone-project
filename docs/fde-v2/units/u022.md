**Learner status: Not started.** This dependency unit spans Day29 (primary60) and Day30 (primary30 + support30). Its accepted total is 90 primary minutes plus30 support; the calendar rows, not this total, govern the assigned daily slices.

## Prerequisites and teaching

Prerequisites: U011 versioned ingestion and U019 generated RAG contract. This is a local, single-user synthetic prototype. It does not establish authentication, tenant isolation, public exposure or production security.

Read Python's official [`pathlib` path resolution and `is_relative_to` documentation](https://docs.python.org/3/library/pathlib.html#pathlib.PurePath.is_relative_to) and OWASP's [Input Validation Cheat Sheet, “File Upload Validation”](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html#file-upload-validation). Resolve an untrusted filename, ensure it remains inside the fixture root, reject symlink traversal, require a regular file with an allowed fixture suffix, and enforce a positive bounded byte count. An extension alone does not establish safe content.

Read OWASP's [Cross Site Scripting Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html) for why generated text must be rendered as text, not executed as HTML. Inspect the supplied UI; do not implement general frontend plumbing.
