# Assistant-supplied architecture notes

This window keeps the workflow synthetic, offline and reference-only until actual evidence satisfies its entry gate. The assistant chooses and explains the architecture; the learner implements and tests it. No capstone design proposal or post-hoc architecture justification is assigned. System-design practice remains in the separate interview question bank.
