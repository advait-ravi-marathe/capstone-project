# Day 123 — 2027-02-23: Keep recovery decisions across fresh JVMs

## Scope

Prove hold and receipt survive a fresh application JVM against the same running disposable PostgreSQL. Await and clean up every child on all paths.

### Worked trace

JVM A persists a quarantine for A. Fresh JVM B retries eligible B while A remains held. After explicit release, a child JVM commits A's receipt and is terminated after the real transaction commit but before acknowledgment starts. JVM C reconciles the same receipt; assert distinct PIDs, unchanged receipt payload/time, retained quarantine/release history, source snapshot, and acknowledgment-only change. PostgreSQL stays running; this is not a database crash guarantee.

Focused reading: [Java 21 Process API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Process.html) — reading focus: Bound child waits, terminate and await both processes on every path.
