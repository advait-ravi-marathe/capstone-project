## Assistant-supplied architecture

Count each hit once; precision uses the fixed denominator 3 even for a short result, while recall divides by the distinct positive target count. Empty-target cases are explicitly non-evaluable. See [the complete day-by-day architecture notes](../assistant-architecture-notes.md#day-174). The learner implements and tests this decision; no capstone design proposal is required.

## Practice

Using supplied typed recommendation and target inputs, compute hits, positive-target count, Precision@3 = hits/3 and Recall@3 = hits/target_count. Keep the fixed-slot denominator even for a shorter list.

## Worked example

Recommendations [b, a], positives {a, c}: one hit, Precision@3=1/3, Recall@3=1/2. Empty candidates with a positive target give zero, not NaN.
