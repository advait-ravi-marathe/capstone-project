## Practice

Using supplied typed recommendation and target inputs, compute hits, positive-target count, Precision@3 = hits/3 and Recall@3 = hits/target_count. Keep the fixed-slot denominator even for a shorter list.

## Worked example

Recommendations [b, a], positives {a, c}: one hit, Precision@3=1/3, Recall@3=1/2. Empty candidates with a positive target give zero, not NaN.
