### Two completed transactions, not one enclosing transaction

Capture once; read one bounded page only. For each item commit receipt before ack; prove receipt visible from an independent raw connection at ack. Reject ambient transaction before any store call; stop visibly on first failure.

Focused source: [Spring programmatic transactions](https://docs.spring.io/spring-framework/reference/data-access/transaction/programmatic.html).

### Worked row-state trace

Capture batch K1/K2 once → receipt K1 commits → ack K1 commits → receipt K2 fails → stop. K1 remains delivered; K2 remains pending. No next-page loop runs and committed progress is reported.
