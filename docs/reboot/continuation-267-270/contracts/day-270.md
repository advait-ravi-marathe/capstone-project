## Gate, status and scope

Current missing or failed evidence becomes an explicit recovery item; it is not a permanent failure and the checker must permit valid future evidence. Run only selectors whose prerequisites are eligible. An unimplemented learner TODO is an expected learner-task outcome, not CI/infrastructure failure or completion. The closeout inventory records assignments only; it must not create learner evidence. The exact 40-hex source commit is distinct from each 64-hex artifact digest. AWS study is offline and guide-version checked at study time; no exam booking, paid call, credential or cloud action. System design remains only in separate question-bank sessions. Algorithm practice remains in the separate [DSA preparation repository](https://github.com/advait-ravi-marathe/dsa-prep/tree/859e161f6553e9aca8dc501fda152780cec66ef0); this repo adds no DSA scripts or tracker.
