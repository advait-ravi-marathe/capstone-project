# Interview practice materials

Use these materials as a practice aid for the existing CoverStory roadmap.
The daily EAI contract, acceptance command, and exact course bridge remain the
source of truth for capstone implementation. The assistant supplies each
capstone architecture decision and concise rationale; learner proposals are
made only while answering questions from the interview question set.

- [36 original practice questions](question-bank.md)
- [First 12 deep-practice sessions](deep-practice.md)
- [Reusable design patterns](pattern-library.md)
- [45-minute mock structure and rubric](mock-rubric.md)
- [Pre-answer proposal sheet](design-proposal-template.md)

For a dedicated interview question, save the learner's own proposal before
hints, model answers, or AI feedback. Mark assistance honestly. A question,
mock, or test passing does not by itself complete an EAI contract.
