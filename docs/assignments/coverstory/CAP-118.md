## Contract and expected outcomes

Both candidate lists use the same ordered query IDs and relevance labels. For lexical ranks `[1,2,4,null]`, Recall@3 is `0.5` and MRR `0.4375`. For precomputed embedding ranks `[2,3,1,null]`, Recall@3 is `0.75` and MRR approximately `0.4583333333333333`. The unsafe scope probe still has a measurable ranking score, but `br1` must produce `UNAUTHORIZED_SOURCE:q3:br1` and a promotion veto independently of recall.

Recommended decision for this tiny synthetic fixture: keep lexical baseline and do not promote. The precomputed candidate is illustrative only; a four-query sample does not establish quality, and no actual embedding model or production source isolation was evaluated. Report rank arrays and denominator alongside aggregates; an empty dataset or missing query row is invalid rather than 100%.
