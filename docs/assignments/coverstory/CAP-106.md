## Contract

- Allow only a `READER` principal using TLS for GET, when principal, explicit owner and registered key owner all match.
- Require a known canonical key and consistent revision identity. Deny path traversal, unknown keys, null owner, writes, and unsafe transport before the local fetch.
- A denial contains no snapshot or foreign metadata. Successful `read` invokes exactly one local fetch.
- Preserve the revision label: historical `r1` remains historical and cannot stand in for accepted current `r2`.
- Do not add mutation capability or any cloud/network dependency.

The independent fixture/policy oracle is `CAP106InstructorInfrastructureTest`; run with `mvn -Dtest=CAP106InstructorInfrastructureTest test`. It checks the five saved scenarios and defect witnesses without calling learner logic. It makes no production security claim.
