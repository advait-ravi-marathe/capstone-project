# CAP-169 — Parse bounded Retry-After values

The saved contract exercises a deterministic parser using a fixed clock. It accepts a nonnegative whole number of seconds or an HTTP date, returns `WAIT` for a delay at or below 30 seconds, returns `STOP_LONG_DELAY` above 30 seconds, reports malformed values as `INVALID_HEADER`, and distinguishes a missing value as `ABSENT`. A past HTTP date produces `WAIT` with zero duration.

This parser only interprets a header. It does not decide whether an operation can be retried, initiate provider traffic, or perform a payment effect. In particular, a payment create/capture timeout still requires reconciliation; a parsed wait is not retry authorization.
