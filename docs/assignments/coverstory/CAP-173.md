## Learner task

Implement the TODO in [`ReconcilePaymentAuditUtcBoundaries`](../../../src/main/java/capstone/coverstory/payments/ReconcilePaymentAuditUtcBoundaries.java). Select only the authenticated owner's journal IDs in the half-open interval `[startInclusive, endExclusive)`, reject a missing owner or invalid range before reading, and reconcile count to the returned ID list. Preserve the saved sorted-range/binary-search DSA practice; this Payments SQL seam is a separate read-only persistence exercise.

The query joins `payments.payment_journal` to `payments.payment_intent`, uses bound `TIMESTAMPTZ` values and the `payments` module's public read port. It accepts no owner ID in the URL. It does not create or change a payment, refund, dispatch, or cover state.
