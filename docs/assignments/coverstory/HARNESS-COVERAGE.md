`harness-matrix.json` is a generated index for 12 bounded 50-day JSON partitions under `harness-matrix/`, all derived from the canonical 600-card source. ## Current verified state

### Why the assignable counter is zero

`assignable_now=0` means no learner contract is marked complete/mastered; it is not a count of runnable instructor exercises. The matrix separately reports instructor scaffolds, `ready_to_attempt`, and learner results. The two readiness issues below are independent and must not be collapsed into that mastery counter:

1. **Unmeasured rehearsal:** the oracle, fixtures and named commands may run, but the saved 95-minute capstone slice has not been rehearsed with actual learner work. All 76 authored scaffold records still lack timebox rehearsal; 57 are marked `CONDITIONAL_SCAFFOLD_NOT_REHEARSED`, while 19 early-day records are `READY_TO_ATTEMPT` based on instructor setup/readiness evidence. An expected TODO failure is not a rehearsal or mastery result.
2. **Missing instructor runtime:** some contracts additionally need a real local module/runtime boundary before their saved flow can be attempted (for example Spring auth routes, a product-owned transaction/worker, a key-retention adapter, an actual artifact pair, or a React/API/PostgreSQL path). A standalone oracle can still support focused practice, but cannot substitute for the missing integration. Each family note lists the exact gap. CAP-90 now has a real disposable-PostgreSQL ciphertext/revision storage witness, but production authorization, retained-key restore and a product route remain missing; CAP-110 has a pure reference gate but no Spring/React submission flow.

The matrix keeps `CONDITIONAL_SCAFFOLD_NOT_REHEARSED` separate from `NOT_SCAFFOLDED`; each `coverage_note` identifies additional runtime blockers. For example, CAP-60's isolated transaction HTTP witness works but the product command is absent; CAP-90 has ciphertext persistence but production auth/key restore is absent; CAP-110 has a pure gate but no Spring/React submit path. Conversely, where a scaffold has the required local runtime, the remaining obstacle may only be the unmeasured 95-minute rehearsal. Do not infer assignability or learner completion from a green fixture oracle.
