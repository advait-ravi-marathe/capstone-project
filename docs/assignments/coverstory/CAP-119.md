## Contract

- Owner scope comes from the authenticated principal; a request `ownerId` cannot grant authority.
- Support must be explicitly assigned to the requested case before candidate lookup.
- Every returned row is rechecked against authorized owner and requested case before model or response serialization.
- A deny or scope violation returns no source text. The BETA_CANARY sentinel must not reach either sink.
- Use only synthetic evidence. No cross-module repository access.
