## Scope and limits

Submission persists only as `SUBMISSION_PENDING`, with a separate pending dispatch intent. It does not mean insurer submission or active cover. The test harness calls no external service and does not implement production authentication, application API, quote/payment validation, client UI, reconciliation worker, or durable production idempotency. Cancellation and unknown-outcome checks exercise only the disposable instructor schema. The learner acceptance tests are separate and are expected to stop at the preserved TODO.
