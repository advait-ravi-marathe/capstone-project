# CAP-107 — Validate reviewed revision quote manifests

This instructor-prepared harness supports the saved contract for validating an immutable synthetic manifest that binds exact rating bytes, options, source and current terms. It does not implement the learner’s validation logic or accept a quote.

## Files and commands

- Learner seam: `src/main/java/coverstory/modules/application/api/CAP107Seam.java`
- Learner acceptance: `src/test/java/coverstory/modules/application/CAP107AcceptanceTest.java`
- Independent oracle: `src/test/java/coverstory/modules/application/CAP107InstructorInfrastructureTest.java`
- Synthetic fixture: `fixtures/coverstory/CAP-107/synthetic-v1.json`
- Run infrastructure only: `mvn -Dtest=CAP107InstructorInfrastructureTest test`
- Run learner contract separately (expected failures at TODO): `mvn -Dtest=CAP107AcceptanceTest test`

## Contract

The seam is `validateReviewManifest(ReviewManifest, ExactBytes, SupportedSchema) -> ManifestResult`. The expected exact-byte identity and row count are checked before issuing a review descriptor. A repeated manifest ID with a changed digest conflicts; unknown schemas or required total/tax fields leave a quote unavailable. Stale scenario or configuration hashes require a new quote. Unconfirmed extraction and an `UNSURE` disclosure may remain a stored draft with specific readiness blockers.

A descriptor identifies initial and revised quote references for review. It never accepts the revision or changes payable values. The fixture is synthetic and has no insurer/payment calls. The learner’s implementation remains explicitly TODO.

## Coverage and limits

The independent oracle has seven tests covering the saved positive and negative boundaries plus malformed digest, row count and blank identity witnesses. The acceptance suite has five scenario tests. Instructor tests establish reference behavior and fixture integrity; they do not prove learner implementation. No frontend binding, database immutability adapter, insurer integration, or payment operation is included.
