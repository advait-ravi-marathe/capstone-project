preparation benchmark is restricted to OpenAI, Anthropic, Google/DeepMind,

## How the sample affects preparation

The first preparation target is **AI Product / Applied AI Software Engineer**:
build substantial AI product behavior, measure it against independent
evaluation sets, handle retrieval and failure cases, and integrate it into a
working application. FDE and customer-deployment roles are a later application
of those skills, with discovery, enterprise integration, and real delivery
evidence. Research Scientist is not the default target for this roadmap.

The three projects remain CoverStory AI, StreamForge AI, and Developer
Workflow Assistant. Shared evaluation and observability supports all three.
This sample supports those existing project directions; it does not add
employer-specific frameworks, mandatory feature lists, or new certifications.
The assistant selects and explains capstone architecture; the learner is not
assigned architecture proposals. No role page, project calendar, or local
fixture proves professional ownership, India hiring availability, or a job
outcome. Recheck openings, location eligibility, titles, and requirements
before applying.
